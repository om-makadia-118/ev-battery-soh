# Source datasets, citations and licence notes

Raw files (about 11.7 GB) are NOT stored in this repository. Download them from the original sources below and follow `docs/DATASETS.md` for the expected folder layout. `data/processed/unified.csv` is a derived table built from these sources; reuse of it is subject to the terms of each source.

| Dataset | Source | Citation | Licence / terms |
|---|---|---|---|
| NASA PCoE battery data | https://www.nasa.gov/content/prognostics-center-of-excellence-data-set-repository | B. Saha and K. Goebel, "Battery Data Set", NASA Prognostics Data Repository, NASA Ames Research Center, 2007 | The repository asks users to acknowledge the repository and the data donors |
| CALCE CS2 | https://calce.umd.edu/battery-data | W. He, N. Williard, M. Osterman, M. Pecht, J. Power Sources 196(23), 2011 | Check the terms on the CALCE page before redistributing |
| XJTU | https://zenodo.org/records/10963339 | F. Wang et al., Nat. Commun. 15, 4332 (2024), doi:10.1038/s41467-024-48779-z | Check the licence shown on the Zenodo record |
| Oxford Battery Degradation Dataset 1 | https://ora.ox.ac.uk/objects/uuid:03ba4b01-cfed-46d3-9b1a-7d4a7bdf6fac | C. Birkl and D. Howey, University of Oxford, 2017 (also cite C. R. Birkl, PhD thesis, Oxford, 2017) | Open Database License (ODbL 1.0): attribution and share-alike apply to derived databases |
| MATR (MIT-Stanford-Toyota) | https://data.matr.io/1/projects/5c48dd2bc625d700019f3204 | K. A. Severson et al., Nat. Energy 4, 383-391 (2019), doi:10.1038/s41560-019-0356-8 | Check the terms on the TRI data page |

If you are unsure whether you may redistribute the derived `unified.csv`, remove it from the repository and keep only the code and `results/` files.
